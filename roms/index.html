How to add & manage ROM files (Archivist Guide) ▾

This repository uses a static architecture. To add or update cartridge dumps:

  1. Place your ROM dumps (e.g. .gba, .gbc, or .gb) into the roms/downloads/ directory.
  2. For Game Boy, Game Boy Color, and Game Boy Advance games, clicking ▶ Play will instantly stream and boot the game in the in-browser retro player!
  3. Edit roms/index.html and register the entry in the ROM_CATALOG array:
    fileName: "Pokemon - Emerald Version (USA, Europe).gba", // Points to your actual cartridge dump
  4. Commit and push to GitHub. GitHub Pages serves the downloads and browser emulator with zero server configuration.
